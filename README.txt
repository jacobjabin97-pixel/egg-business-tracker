EGG BUSINESS TRACKER

Files:
- index.html: the complete web app
- manifest.json: installable web-app settings
- service-worker.js: offline caching

HOW TO USE:
1. Upload these files to a web host that supports static HTML.
2. Open the web address in Chrome on your Android phone.
3. Use Chrome menu (⋮) -> Add to Home screen / Install app.
4. Your records are stored locally in the browser on that phone.
5. Use Export Backup regularly and keep the JSON backup somewhere safe.

IMPORTANT:
This version stores data only on the device/browser. It does not sync between phones.
